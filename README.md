# SilverGuide 银龄引路人 — M1 基础产品

> 对应《SilverGuide 技术需求规格说明书 V1.0》第 12 章「阶段 M1：基础产品」。
> M1 已提供无需注册、无需 AI 服务即可走完的两套完整模拟训练；AI 截图分析、语音播报、PWA 与公网发布按里程碑留待 M2–M4。

## 1. 本阶段功能

- 首页、训练中心、训练页、学习档案、设置页及基础导航。
- 适老化按钮、字体缩放、高对比度、简短首次使用说明、文字标签与键盘可操作控件。
- 医院预约挂号、手机打车两套各 6 步的虚构模拟训练。
- 确定性任务状态机：正确前进、错误不跳步、连续两次错误恢复详细提示、求助、返回、重新开始、退出、恢复。
- L1 / L2 / L3 三级基础提示；首次任务默认 L1，再次练习逐步减少提示，训练中可手动切换。
- IndexedDB + Dexie 本地学习档案：开始/完成记录、最近练习时间、完成用时、错误次数、求助次数、最终提示等级，以及一键清除。
- 存储不可用时训练继续运行，并明确提示记录无法持久化；AI 服务不可用时首页明确标注，模拟训练不受影响。

所有医院、科室、时间、路线、车型和费用均为演示数据；训练页显著显示「模拟练习，不产生真实订单」，不生成真实医疗预约、出行订单或支付行为。

## 2. 技术栈

| 层级 | 采用 |
|---|---|
| 前端 | Vue 3 + TypeScript（严格模式） |
| 构建 | Vite 6 |
| 样式 | Tailwind CSS 3 |
| 路由 / 状态 | Vue Router 4 / Pinia 2 |
| 本地进度 | IndexedDB + Dexie 4 |
| 单元测试 / 组件测试 | Vitest 3 + @vue/test-utils + jsdom + fake-indexeddb |

显示与声音偏好仍使用轻量 `localStorage`（沿用 M0 键名以保留已有选择）；学习进度和历史记录使用 Dexie。PWA、Playwright 与真实语音播报按 M3–M4 计划引入，本阶段不提前安装。

## 3. 快速开始

需要 Node.js ≥ 20.19（M1 在 Node 22.22.2 上验证）。

```bash
npm install        # 安装依赖
npm run dev        # 本地开发：http://127.0.0.1:5173
npm run typecheck  # TypeScript 严格模式检查
npm run test       # 单元测试与组件集成测试
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 生产构建预览：http://127.0.0.1:4173
npm run verify     # typecheck + test + build + 前端凭证扫描
```

M1 不需要 `.env` 文件即可安装、启动、测试与构建。`.env.example` 仅描述后续阶段的服务端环境变量，禁止改成 `VITE_` 前缀。

## 4. 路由

| 路由 | 页面 | M1 功能 |
|---|---|---|
| `/` | 首页 | 产品入口、首次说明、字号与语音偏好 |
| `/practice` | 训练中心 | 两类训练及继续练习状态 |
| `/practice/hospital-registration` | 医院挂号训练 | 六步模拟与结果 |
| `/practice/taxi-ride` | 打车训练 | 六步模拟与结果 |
| `/progress` | 学习档案 | 记录、统计与清除 |
| `/settings` | 设置 | 字体、高对比度、默认提示等级、数据清除 |

`/ai-helper` 与 `/about` 属于后续阶段，本阶段不建立空壳页面。未知路径回退首页。

## 5. 目录结构

```
src/
├── components/   适老化按钮、字号/提示控制、仿真按钮、全局导航、两套仿真界面
├── views/        首页、训练中心、训练页、学习档案、设置页
├── router/       M1 基础路由
├── stores/       用户设置与练习状态（Pinia）
├── tasks/        两套演示任务配置
├── engine/       确定性任务状态机（纯函数）
├── services/     M0 AI 契约、校验器、图片与客户端
├── repositories/ IndexedDB + Dexie 学习进度仓储
├── types/        §6 数据模型 + §7.2 AI 接口契约
└── utils/        ID、坐标与格式化工具
tests/unit/       M0 与 M1 单元测试、组件集成测试
tests/e2e/        M3 Playwright（占位）
scripts/          凭证扫描、Cloud Agents 验证脚本
docs/             部署说明、AI 契约、M0/M1 验证报告
```

页面不包含任务判定逻辑；仿真页面的目标按钮使用真实 DOM `id`，目标由任务配置与状态机共同决定，不由模型生成坐标。

## 6. 安全边界

- 浏览器不持有、不读取、不发送任何 Qoder PAT / SAT 或模型 API 私钥；`npm run verify:secrets` 会检查源码与 `dist/`。
- 训练流程不调用网络或 AI 服务；服务不可用时不会用固定答案冒充 AI 分析。
- 学习档案只存在本地 IndexedDB，不包含姓名、手机号、身份证号等个人身份信息。
- AI 响应校验、坐标校验与失败降级沿用 M0 契约，M2 接入真实服务时继续生效。
