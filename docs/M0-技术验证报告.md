## 结论摘要

**代码基线已达成并通过本地验收；M0 通过条件尚未完全达成。**

- ✅ **已完成**：Vue 3 + TypeScript 严格模式项目、依赖安装、最小首页与移动端优先的适老化布局、严格类型检查、65 个单元测试、生产构建、本地启动与预览、无鉴权访问、前端凭证泄露扫描、§6 数据模型与 §7.2 接口契约固化、AI 响应校验与降级逻辑、可替换 Provider 接口、Cloud Agents 实调验证脚本。
- ✅ **技术路线已验证（文档层 + 可执行验证方案）**：Qoder Cloud Agents 明确支持图片输入与结果返回；服务端凭证可通过 Sites Secrets（只写不可读回）或 Vault（加密存储）保存；存在明确的替代实现（同源服务端适配层 + 结构化校验 + 失败降级）。
- ❌ **未完成**：Qoder Sites 公网发布、未登录访客匿名访问验证、Cloud Agents 真实图片调用、账号额度与服务能力实测。原因是当前环境为 WorkBuddy 工作区，无 Qoder 账号、`qodercn` CLI、PAT/SAT 或 Agent/Environment ID，无法执行平台侧操作。

因此严格按 §12「通过条件：网站可以公开访问，且 AI 集成路线已经得到验证或有明确可行的替代实现」判定：**后半项满足，前半项待在 Qoder CN 内执行**。`docs/部署说明.md` 提供了可直接执行的步骤与验证清单。

## 3. 官方技术资料核验结论

| 核验项 | 结论 |
|---|---|
| 图片输入 | `user.message` 的 `content[]` 支持 `image` 块，来源为 `base64` / `url`(HTTPS) / `file`(File ID)；可只发图片 |
| 图片限制 | `image/png`、`image/jpeg`、`image/webp`、`image/gif`；单图 base64 编码文本 ≤ 10 MiB，宽高各 ≤ 8000px；每条消息 ≤ 100 个图片块；需支持图片输入的模型 |
| 结果返回 | SSE `/events/stream` 或 `GET /sessions/{id}/events` 读取 `agent.message`；须等 `session.status_idle`（running 时发送返回 409） |
| 认证 | `Authorization: Bearer $QODER_ACCESS_TOKEN`（PAT/SAT），`https://api.qoder.com.cn/api/v1/cloud` |
| 额度控制 | Session `budget.max_credit_cost` 上限 + `usage.total_credits` 统计；验证脚本已设 5.00 Credits 上限 |
| 服务端凭证 | CLI `/sites` 环境变量「只写不可读回」；Cloud Agents Vault 加密存储且 API 不返回密钥 |
| 匿名访问 | 个人版可选「任何人都可访问」并需「允许公开访问」确认；**企业版不支持对外公开** |
| 套餐限制 | 个人 Free 版仅静态网页部署，不支持数据库与存储；站点限免期有账号级用量额度，高用量站点可能被暂停公开访问 |

详细契约见 `docs/ai-provider-contract.md`，部署步骤见 `docs/部署说明.md`。

## 5. M1 实施建议（按优先级）

1. **先关闭 M0 阻塞项**：在 Qoder CN 发布 `dist/`、设置「任何人都可访问」、用无痕窗口与其他浏览器验证；用 `npm run verify:ai` 完成一次真实图片调用并确认额度与延迟。保存全部截图作为参赛证据。
2. **确认部署约束**：SPA fallback、资源基础路径、Server Functions 可用性。据此决定 `base` 与路由模式，并把 `/api/vision/analyze` 落到服务端适配层。
3. **再进入 M1 功能开发**：按 §6 已定义的类型落地 `demoData`（医院挂号 / 打车两套 Task）、`taskEngine` 确定性状态机、`progressRepository`（IndexedDB + Dexie）、四个页面与路由；补写 §10.1 中任务迁移、错误操作、提示等级、进度恢复的单元测试。
4. **保持解耦与边界**：UI 不含任务判断与 AI 请求逻辑；模型不得改写任务事实；所有模拟页面显著显示「模拟练习，不产生真实订单」；凭证继续只留服务端。
5. **测试策略**：M1 起引入 Playwright，按 §10.2 路径 A/B/D 建端到端用例；路径 C 待 M2 AI 服务上线后补齐。
