# SilverGuide M1 基础产品验收报告

**报告日期：** 2026-11-05  
**对应文档：**《SilverGuide 技术需求规格说明书 V1.0》§3.1–3.4、§3.8、§3.9、§4.1–4.2、§6、§10.1、§12（M1）  
**代码版本：** `0.2.0-m1`  
**验证范围：** 本地代码、组件集成、生产构建、本地 HTTP 访问；不包含 Qoder Sites 平台侧发布。

---

## 1. 结论

**M1 的七项交付已在代码层面完成，本地验收链全部通过。**

- 首页、训练中心、训练页、学习档案、设置页与基础导航均可用。
- 医院挂号、手机打车各有 6 个可操作步骤，均存在从进入训练到查看结果的完整路径。
- 正确操作、错误操作、求助、返回、重新开始、退出和刷新恢复均由确定性状态机处理。
- L1 / L2 / L3 三级基础提示与连续错误恢复机制可用。
- 学习进度使用 IndexedDB + Dexie 保存，可读取、刷新恢复和一键清除。
- 训练不依赖网络或 AI 服务；AI 服务不可用时首页明确标注，模拟训练仍可完成。
- 类型检查、125 个测试、生产构建、凭证扫描和六条本地路由访问均通过。

TRD §12 没有为 M1 单独定义平台侧通过条件。M0 遗留的 Qoder Sites 公网发布与匿名访问实测、Cloud Agents 实调、账号额度实测仍属于平台侧阻塞项，M1 未把它们写成已完成。

## 2. 实施假设

1. M1 严格按 §12 的七项交付执行；`/ai-helper`、真实 AI 调用、SVG Overlay、Web Speech API、PWA、Playwright 多端测试分别留到 M2–M4。
2. 两套模拟任务各安排 6 个可验证的用户操作：进入首页、按场景选择目标、核对信息、确认模拟业务、查看结果并结束练习。所有业务数据均为虚构演示数据。
3. 学习进度和历史记录使用 IndexedDB + Dexie；M0 的字体、高对比度与语音偏好继续使用 `localStorage` 的既有键名，避免清除用户已有显示设置。
4. 首次练习默认 L1；完成 1 次后默认 L2，完成 2 次及以上默认 L3。用户选择的更少提示偏好只在已经完成过至少一次时生效。连续两次错误立即恢复 L1。
5. 刷新训练页时自动恢复最近一次 `active` 会话；已完成结果保留在学习档案中。重新开始生成新记录，不覆盖历史记录。
6. M1 的基础提示以文字说明和真实 DOM 目标高亮为主；L1 的语音部分由 M2 接入，界面不宣称当前已有朗读能力。
7. 本地组件集成测试覆盖路径 A / B / D 的业务逻辑；M3 再用真实浏览器的 Playwright 完成多端端到端验证。

## 4. 主要代码改动

- `src/tasks/demoData.ts`、`src/engine/taskEngine.ts`：两套任务配置与 12 个状态机 API，输入时间/ID 全部由调用方注入，业务规则不依赖模型或网络。
- `src/repositories/progressRepository.ts`：Dexie 仓储、内存仓储与统一 `ProgressStore` 接口；写入前将 Pinia 响应式快照显式转换为纯数据记录。
- `src/stores/practice.ts`：练习加载、动作、帮助、返回、提示调整、重启、退出、记录读取与清除；任何一次保存失败都显示明确提示且保留当前页面内的训练状态。
- `src/views`：首页、训练中心、训练页、学习档案、设置页；训练结果与任务统计统一展示。
- `src/components`：应用导航、字号/提示控制、真实 DOM 仿真按钮与两套仿真界面。
- `src/router/index.ts`：注册 M1 五类路由；`src/App.vue` 统一挂载全局导航。
- `tests/unit`：新增状态机、任务配置、仓储、完整训练路径、设置、训练中心、导航、格式化测试；更新首页测试。
- `package.json` / `package-lock.json`：版本 `0.2.0-m1`，新增 `dexie@4.4.7`、`fake-indexeddb@6.2.7`。
- `index.html`、`README.md`、`docs/部署说明.md`：版本描述、使用说明、目录结构和 M1 路由部署检查项。

### 联调中实际修复的问题

1. Pinia 状态是响应式代理，直接对快照调用 `structuredClone` 会触发 `DataCloneError`，导致保存被静默降级。仓储改为显式构造纯数据记录；刷新恢复测试随后通过。
2. 任务配置中的科室、时段、目的地、按钮名称与仿真界面存在不一致。已统一为任务配置中的文案，并在完整路径测试中逐步核对当前指导文字和目标 DOM `id`。
3. `getDefaultHintLevel(0, 3)` 曾允许首次练习使用 L3，不符合「新任务默认 L1」。已改为首次任务固定 L1，并补充集成测试。
4. 测试曾因 Dexie 异步完成时机不稳定而提前断言；已改为等待「加载完成且目标按钮出现」的明确条件，不使用固定延时。
