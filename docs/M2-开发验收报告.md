## 三、实现要点

- `src/views/AiHelperView.vue`：输入、隐私确认、图片预览、异步状态、结果展示与 SVG 标注。不持久化截图；更换图片、取消及离开页面时清理对象 URL 和请求状态。
- `src/services/imageService.ts`：文件大小和类型检查；在需要时等比例缩放至最长边 1800px 并编码为受支持格式。图片处理失败时给出明确提示。
- `src/services/speechService.ts` 与 `SpeechControls.vue`：管理单一语音播放通道，避免多条互相叠加。
- `server/visionApi.ts`：`POST /api/vision/analyze`，服务端对 multipart、字节大小、常见图片头和尺寸进行检查，限制请求频率及并发量，控制超时；服务端返回统一的业务响应。
- `server/qoderVisionProvider.ts`：按 M0 已记录的 Cloud Agents 接口契约实现新建 Session、发送图片与文字、轮询结果、解析 JSON 与清洗。每次会话单独处理，不复用其他用户会话；预算上限为 5 Credits。
- 配置缺失时明确返回 `NOT_CONFIGURED`；实际模型结果从未以固定答案代替。测试中的成功/故障数据仅供自动化测试使用。

## 六、部署及隐私注意事项

本地开发和构建预览使用 Vite Node 中间件；它不是正式公网生产服务。进程内频控不跨实例共享，公网环境需进一步按实际平台限制资源、费用、访问频率及模型权限。取消等待会终止本机请求和轮询，但不能保证已经发送的上游会话立即停止或取消费用。远端服务可能处理及保留已发送的数据，必须在真实上线前核实其保留策略。
