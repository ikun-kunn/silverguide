## 发布前配置边界

- `SILVERGUIDE_TRUSTED_PROXY_CIDRS` 默认不信任任何代理。必须先从部署方确认确切、受控的代理网络及可信转发链。错误配置保守回退至直连地址。`SILVERGUIDE_PUBLIC_ORIGIN` 只校验 Origin，不能替代代理信任。
- 默认单 IP / 全局每分钟为 4 / 60 次，总并发为 4、单 IP 并发为 1，每日单 IP / 全局为 20 / 50 次；按用户实际预算配置。限流不是账号身份认证，同一 NAT 后多个终端可能共享地址；计数仅在当前 Node 进程内保存，不能保证跨实例或重启后的持久配额。
- 请求体保护还应配合正式反向代理/平台的上传上限和资源限制；当前仅通过本地逻辑及内存流测试，不声称已对 Qoder Sites 的实际代理行为进行压测或验收。
- 静态凭证扫描只识别受支持的秘密特征与静态赋值，不代替完整数据流分析、服务端 Secrets 配置和权限审计。

部署配置见 `README.md` 和 `M4-发布与参赛材料.md`。父级报告中的历史功能验收不替代本次 RC.3 实机验证。
