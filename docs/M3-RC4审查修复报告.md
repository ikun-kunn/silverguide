# SilverGuide — M3 RC.4 审查修复报告

日期：2026-11-23  
版本：`0.4.0-m3-rc.4`

## 1. 十项修复

| 编号 | 修复 | 验证 |
|---|---|---|
| 1 | AI 输入及输出独立风险判断；明确敏感请求不发往上游；敏感结果仅展示和朗读系统固定提醒，不保留模型指导与坐标。 | 校验器、同源 API、页面组件回归；新增 H 浏览器场景。 |
| 2 | Dexie v2 新增代次元数据；清除和保存在同一覆盖两表的事务中比较代次；其他标签页通过 liveQuery 同步，旧代次写入被拒绝。 | 两个独立连接、两个 Pinia 实例、代次观察及 v1 数据库升级测试；新增 G 浏览器场景。 |
| 3 | PWA 显式更新流程先确认学习进度，监听新控制器接管，刷新前再次确认写入，超时可重试；卸载时释放监听。 | 模拟 Worker 接管、保存失败和一次性刷新测试。 |
| 4 | 档案仓储返回经校验的安全摘要，无法读取的记录标记为不兼容，原始 IndexedDB 数据保留；不计入有效完成次数。 | 损坏记录、档案渲染及清除测试。 |
| 5 | 所有浏览器选择的图片均从像素重新编码，上传文件名规范化。 | 小图片重新编码、预览准备、multipart 文件名测试。 |
| 6 | 训练中心和仓储共享最新记录排序，最新会话非 active 时不恢复较早的会话。 | 按版本恢复、统计和最新状态测试。 |
| 7 | 每段语音配置有界 watchdog，未触发结束/错误事件时停止播报并明确降级为文字。 | 模拟语音停滞、正常结束及取消测试。 |
| 8 | 退出训练保存期间，组件卸载、路由变化或会话切换时取消迟到跳转。 | 保存挂起期间卸载组件的回归测试。 |
| 9 | 仅在未完成的上游执行中断或失败时尝试 cancel；成功不取消 idle Session，响应前校验 abort。 | 主流程四次请求、失败取消及迟到响应测试。 |
| 10 | 语音分段长度确保至少一个字符。 | 小数边界回归测试。 |

## 2. 实际验证

- `npm run verify` 退出码 0：TypeScript、23 个 Vitest 文件共 **212/212** 项、前端及服务端生产构建、52 个前端文件及 20 个服务端/脚本文件凭证扫描通过。
- PWA 产物检查：7 个静态预缓存文件、PNG 安装图标与 manifest 完整。
- Node 脚本测试 **7/7** 通过；20 张合成 PNG 评测语料仅完成本地核验，未上传，未测量真实模型准确率。
- `npm run test:e2e -- --list` 枚举 **16 项**，8 个场景 × 移动/桌面视口。默认 Playwright Chromium 尚未安装；尝试使用本机 Edge 启动 E2E，当前执行环境拒绝访问 `127.0.0.1:8080`，已终止测试进程。未进入实际浏览器用例执行，不计为通过。可在允许本地回环访问的终端运行 `$env:SILVERGUIDE_E2E_CHANNEL='msedge'; npm run test:e2e`。

## 3. 发布前仍需验证

1. 真实浏览器双视口 E2E、实际手机 PWA 安装及两版本更新流程。
2. 真实专用 Cloud Agents 环境、模型准确率及敏感业务安全行为人工复核。规则保护不保证识别全部风险，不伪称 AI 能力已达标。
3. 图片可见隐私仍须由用户遮挡；浏览器像素重新编码不能替代远端数据保留策略审核。Qoder cancel 只尝试中断执行，不表示会话/截图删除或额度回退。
4. 平台同源接口、限额、秘密管理和公开部署需经所有者确认并实测。
