## 4. 验收边界

- PWA 实现已通过进程内逻辑及构建文件检查；不等于已在 Android 或 iOS 实机安装。
- 20 张合成样本和评分器通过本地核验；不等于真实模型达到 80% 准确率。评测说明详见 `docs/vision-evaluation/README.md`。
- Playwright 已作为开发依赖精确锁定并可运行用例枚举，RC.4 新增跨标签页清除和敏感分析结果两个场景。E2E 不纳入 `npm run verify`，须作为发布前独立门禁，即使通过也不等价于实机浏览器体验。
- 当前进程未配置 Qoder 服务端认证变量，且未找到 `qodercn` CLI。未发起真实 Cloud Agents 请求或进行公开发布。
- Qoder 官方资料列出 Agent App Server Functions 与站点 Secrets，但 Free 版仅支持静态站点。需使用真实 Qoder 账号确认运行时实际契约、访问权限、费用和图片保留策略，测试同源 API 并经所有者确认再发布。参见 [站点](https://docs.qoder.cn/qoder/sites)、[CLI Sites](https://docs.qoder.cn/cli/sites)。
- 上游中断处理按 [Cloud Agents Sessions](https://docs.qoder.cn/cloud-agents/sessions) 的 cancel 语义做一次短超时尝试，成功后的 idle Session 不调用 cancel。取消执行不能保证会话/截图删除或费用回退，真实提供方效果需联调。

## 5. 剩余关键路径

1. 配置专用的只读 Qoder Agent、Environment ID 和服务端认证；确认 Credits，跑真实冒烟及模型评测。
2. RC.4 实际运行 Chromium 或已安装 Edge/Chrome 的 16 项 E2E；在 Android Chrome、iOS Safari 和桌面浏览器实际体验。
3. 在 Qoder 真实账号验证动态站点与 Secrets；确认函数限额、图片保留政策、同源路由，预览成功后公开发布。
4. 在知情同意下完成人工体验，记录真实反馈和实际截图；根据赛题提交材料。操作模板见 `docs/M4-发布与参赛材料.md`。
