## 1. 发布路径与关键决策

- 先执行 `npm run verify`，保留完整输出；`npm run build` 生成两个相互独立的目录。
- `dist/` 是前端，包含 Manifest、Service Worker、图标和业务页面；它可静态发布，但未接入 AI 时明确降级。
- `dist-server/index.mjs` 是 Node 服务端产物，仅供服务器执行（同源托管 `dist` 和 `/api/vision/analyze`）。不可直接作为公开静态文件发布。
- [Qoder CN 站点](https://docs.qoder.cn/qoder/sites) 说明 Site 可以与 Cloud Agents 集成，个人 Free 版仅支持静态网页；[Qoder CLI Sites](https://docs.qoder.cn/cli/sites) 说明 Agent App 支持 Server Functions，站点管理面板可设置 Secrets。需要首先在真实账号确认实际动态运行能力、额度及函数契约，不能假设 Vite 或 Node HTTP 常驻服务可直接在 Qoder Server Functions 运行。
- 如果账号支持动态站点：优先使用同源 Server Function，按照平台生成的实际 SDK/运行时契约接入 `server/` 逻辑。验证 multipart、85 秒处理时长、请求限制、秘密变量读取及后端出站能力。
- 如果仅支持静态站点：先完成合法公开的模拟训练和 PWA 体验；若赛题必须 AI 功能完整，需要获得可用动态账号或合法同源后端方案并完成真实联调。不可把私密令牌嵌入浏览器，也不可将 AI 降级误报为真实 AI。

Secrets（通过服务商支持的配置流程填写，不要在聊天或仓库中粘贴真实值）：

## 5. 天池作品介绍帖草稿

**作品名称：SilverGuide 银龄引路人——一步一步学会用手机**

**公开访问地址：** [待 Qoder Sites 发布并验证后填写]

**解决的问题：** 手机预约挂号与出行等生活服务日益普及，部分老年用户面对复杂页面容易误触、不知下一步选哪里。SilverGuide 使用安全的虚构练习场景帮助用户以自己的节奏学习，并提供面向真实手机截图的可解释辅助设计。

**主要功能：** 两套确定性模拟训练（医院预约挂号、手机打车），以三级指导、错误反馈、文字及中文语音帮助完成任务；本机学习档案记录练习用时、错误和求助情况；字体大小、高对比度及误触防护；支持 PWA 安装和静态离线训练；可选 AI 看图指导在用户确认后发送截图，校验分析输出，在可靠情况下对目标区域进行标注。AI 真实能力与公开链接须以发布前实测结果为准。

**技术方案：** Vue 3、TypeScript、Pinia、IndexedDB/Dexie、教学任务状态机、SVG Overlay、Web Speech API、PWA Service Worker、Node 服务端、Qoder Cloud Agents 适配层。运行模拟练习不依赖 AI；AI 认证凭证只存在服务端，模型不代替用户完成真实业务。

**亮点：** 把操作练习从静态图文变成可互动、可逐步摆脱提示的任务；以确定性状态机确保模拟流程正确；对于不可靠识别或敏感业务，保留安全提醒并隐藏位置标注。端侧学习记录无需注册。

**开发/测试证据：** [插入当前 npm run verify 的真实通过结果、Qoder 参与开发过程记录、真实模型评测摘要及发布验证截图；没有的材料留空，不伪造]

**使用方式：** 打开站点 → 开始学习 → 选择场景 → 根据指导完成任务 → 查看学习档案。也可使用 AI 看图（以实际部署是否接入为准）。
